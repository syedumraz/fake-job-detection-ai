# AI Against Fraud: Lightweight & Transparent Detection of Fake Job Postings

This repository contains the implementation for my M.Tech thesis and published research paper:
> **"A Lightweight, Transparent Machine Learning System for Real-Time Detection of Fraudulent Online Job Postings"**  
> *Published in IJCISIM (2026)* | **DOI:** `10.70917/ijcisim-2026-5736` | **Corpus ID:** `292876687`

## Overview
Online recruitment scams pose serious financial and privacy risks to job seekers. Unlike heavy black-box deep learning models, this system focuses on **low computational overhead (real-time speed)** and **model transparency (explainability)** to flag fraudulent job descriptions accurately.

## Key Features
- **Text Preprocessing & Feature Engineering:** Automated cleaning, tokenization, and vectorization of job titles, company profiles, and descriptions.
- **Lightweight Classification:** Optimized machine learning models designed for fast inference without requiring expensive GPU hardware.
- **Model Transparency:** Interpretable feature weights showing *why* a posting was flagged as fraudulent.
